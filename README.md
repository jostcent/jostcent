# jostcent

Repository für die persönliche Homepage — Arbeitstitel **«Kein Tag im Leben …»**.

Fachliche Texte zu Sozialversicherungsrecht, Pflegefinanzierung und zur Grenze
zwischen psychiatrischer und somatischer Pflege.

## Stand

Noch keine Website. Vorhanden ist der redaktionelle Plan:

- [`inhalt/themenplan.md`](inhalt/themenplan.md) — Positionierung, Rubriken,
  elf Themenblöcke mit Rechtsgrundlagen und Risikobewertung, Reihenfolge,
  Querschnittsregeln, offene Entscheide.

## Nächster Schritt

Entscheid Nr. 1 im Themenplan: Hosting und Domain. Ein Repository mit dem
Benutzernamen wird von GitHub Pages als Profil-README behandelt, nicht als
Website. Für eine erreichbare Seite braucht es `jostcent.github.io` oder
Hosting über einen Anbieter wie Vercel.

## Regeln für Inhalte

Verbindlich für jeden Text in diesem Repository, Einzelheiten in Abschnitt 5
des Themenplans:

- Keine Klientendaten, keine rückidentifizierbaren Fallvignetten
  (Art. 321 StGB, DSG).
- Keine namentliche Nennung von Arbeitgebern oder Institutionen (Art. 321a OR).
- Keine Rechtsauskunft im Einzelfall; Hinweistext in jedem Artikel der Rubrik
  Sozialversicherung.
- Jede Zahl, Frist und Anspruchsvoraussetzung mit Primärquelle: Fedlex,
  BSV-Kreisschreiben, Rechtsprechung. Merkblätter sind kein Beleg.
- Jeder Artikel mit Beträgen führt ein sichtbares Feld «Stand».
  Nächster Pflichttermin: **Dezember 2026**, Prüfung aller Beträge auf die
  Werte ab 1. Januar 2027.
